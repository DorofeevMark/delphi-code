# Delphi Code

## README

Keep README.md minimal and user-facing: what the tool does, how to install, upgrade, and uninstall it, the commands, and the settings a user needs. Leave out implementation details such as index manifests and format versions, chunk sizes, locking, key migration, internal libraries, and edge-case behavior. They belong in the code or CONTRIBUTING.md. When adding a feature, add a line or a table row rather than a new section, and prefer cutting text to adding it.
